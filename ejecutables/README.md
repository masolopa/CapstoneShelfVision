# Ejecutables de Regova

- **INICIAR_REGOVA.bat** abre Regova para uso diario. Mantén abierta la consola. Para detenerlo, pulsa Ctrl+C en esa consola.
- **PREPARAR_EQUIPO.bat** prepara Regova en otro PC o repara una instalación. En un equipo nuevo instala primero Python 3.13 x64 y PostgreSQL.
- **CONFIGURAR_CLAVE_CORREO.bat** guarda o cambia la contraseña de aplicación del correo de recuperación.

El cálculo de superficie está habilitado por defecto al usar YOLO con una región marcada. Las opciones de desarrollo, pruebas y mantenimiento están en [herramientas](../herramientas/README.md).
